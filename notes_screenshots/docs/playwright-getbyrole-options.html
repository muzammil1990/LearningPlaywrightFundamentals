Playwright getByRole: The 9 Options

A quick reference for the options object in page.getByRole(role, options).

Syntax: page.getByRole(role, { name, exact, checked, disabled, expanded, pressed, selected, level, includeHidden })
The role is required. All options are optional, and any state option you leave out does not filter anything.

The 9 options

OptionTypeWhat it doesExample
namestring or RegExpMatches the accessible name (button text, label, aria-label, and so on). The most used option.{ name: 'Sign in' }
exactbooleanWorks with name. Default false means case-insensitive substring match. true means case-sensitive, whole-string match. Ignored when name is a RegExp.{ name: 'Sign in', exact: true }
checkedbooleanChecked state of checkboxes, radios, and aria-checked elements.{ checked: true }
disabledbooleanMatches disabled (true) or enabled (false) elements.{ disabled: false }
expandedbooleanMatches aria-expanded state (accordions, dropdowns, tree items).{ expanded: false }
pressedbooleanMatches aria-pressed state of toggle buttons.{ pressed: true }
selectedbooleanMatches aria-selected state (tabs, options).{ selected: true }
levelnumberHeading level, 1 to 6. Also works for other hierarchical roles.{ level: 2 }
includeHiddenbooleanDefault false, so elements hidden from the accessibility tree are skipped. true includes them.{ includeHidden: true }

Examples

// name: partial, case-insensitive by default
await page.getByRole('button', { name: 'sign' }).click();

// exact name
await page.getByRole('button', { name: 'Sign in', exact: true }).click();

// regex name
await page.getByRole('button', { name: /sign (in|up)/i }).click();

// state options
await page.getByRole('checkbox', { name: 'Remember me', checked: false }).check();
await expect(page.getByRole('button', { name: 'Submit', disabled: true })).toBeVisible();
await page.getByRole('tab', { name: 'Settings', selected: false }).click();
await page.getByRole('button', { name: 'Menu', expanded: false }).click();
await page.getByRole('button', { name: 'Bold', pressed: true }).click();

// heading level
await expect(page.getByRole('heading', { name: 'Pricing', level: 2 })).toBeVisible();

// include elements hidden from the accessibility tree
await page.getByRole('dialog', { includeHidden: true });

Tips

  • If a locator doesn't find your element, check the role first. A clickable <div> with no role has no useful role, so getByRole can't see it. Use getByText or getByTestId there, or ask the developers to add proper semantics.
  • Combine options freely, for example getByRole('button', { name: 'Save', disabled: false }).
  • Because name is a substring match by default, { name: 'Save' } also matches "Save as draft". Add exact: true when that causes strict-mode errors.
Remember: name and exact narrow by text, the five state options (checked, disabled, expanded, pressed, selected) narrow by state, level narrows headings, and includeHidden widens the search.
